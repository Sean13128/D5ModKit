Welcome to the D5 Mod Kit

Version 1.1 · what changed: CHANGELOG.md

A modding studio for Disgaea 5 Complete (PC), together with the Outfit System, 175 outfits for 26 characters and a new playable character: Thunderlady, Girl Laharl's lightning alternative.

The short version
  1. Close the game. Extract the zip into the game folder, so you get …\Disgaea 5 Complete\D5ModKit.
  2. Double-click Start D5 Mod Kit.bat in that folder.
  3. Press ⚡ Install & Play (bottom left). The first install takes a minute or two. Have fun.

Nothing else to install: the kit carries its own Python and every library it needs (in the runtime folder). The original game files are backed up before anything changes, and Restore original game… puts them back exactly as they were.

What you need

ItemDetails
WindowsWindows 10 or 11, 64-bit.
The gameDisgaea 5 Complete for PC, in any language setting. This is the Windows version (on Steam), not the Switch or PS4 game. The kit checks the game's program file when it starts; see Troubleshooting if it shows a warning.
Disk spaceAbout 3.5 GB for the kit folder, plus about 1.5 GB of game data the mods add.
A clean gameThe kit backs up the game files the first time it installs. If other mods or tools already changed the game, restore it first (Steam: right-click the game › Properties › Installed Files › Verify integrity of game files).

Setting up (5 minutes)

  1. Close Disgaea 5. The kit can't change files the running game holds open.
  2. Find the game folder. Steam: right-click Disgaea 5 Complete › Manage › Browse local files. It's the folder with disgaea5.exe and Data.
  3. Unblock, then extract. Right-click the downloaded zip › Properties › tick Unblock (if you see it) › OK. This stops Windows from asking about every file. Then right-click the zip › Extract All… and choose the game folder. You get a D5ModKit folder next to disgaea5.exe.
    The kit also works from any other folder (for example Documents\D5ModKit). It looks for the game through Steam by itself, and asks for the folder if it can't find it.
  4. Start the kit: double-click Start D5 Mod Kit.bat. If Windows shows Windows protected your PC, click More info › Run anyway. The first start takes a few seconds longer. The Home page shows Game: …\Disgaea 5 Complete at the bottom. If a red or orange message appears under it, read Troubleshooting.
  5. Install the mods: press ⚡ Install & Play in the box at the bottom left. The kit backs up the original files, writes every enabled mod into the game (about 1–3 minutes the first time) and starts the game. From then on the box shows 🟢 Ready to play, and ▶ Play starts the game.
Antivirus. The mods add two small files the game loads (d5auto.dll, d5core.dll) and change disgaea5.exe. Some antivirus programs distrust unsigned files like these. If yours quarantines them, allow the game folder and the D5ModKit folder.

Your saves

Back up your saves before playing with mods. They are in %APPDATA%\Nippon Ichi Software, Inc\Disgaea 5 Complete (paste that into Explorer's address bar); copy the SaveData folder somewhere safe.

The mods never change your saves, and you can load your existing saves with them. But a save that contains something a mod added (a character wearing a mod outfit) needs that mod installed. Before you remove such a mod, switch the characters back to Default and dismiss the added units, or keep a save from before you used them.

How the kit works

Mods are folders of changes. Every change you make (a name, a colour, a whole new outfit) is saved into a mod under D5ModKit\mods. The game itself isn't touched while you edit.
Install writes them into the game. Install & Play combines every enabled mod and writes the result into the game files. The originals are backed up first, into D5ModKit\state.
"Saving edits to". The box in the sidebar picks the mod your 💾 Save buttons write into. If none is picked, the kit asks for a name the first time you save.
The status box (bottom left) always tells you whether the game has your latest changes: 🟢 Ready to play or 🟠 Changes not in the game yet. Its button does the right thing.

Hover any field or button for an explanation. The Log at the bottom shows everything the kit did.

The pages, one by one

🧙 Characters & Classes

Every character and class: names, stats, aptitudes, movement, weapon mastery, resistances, evilities, learned skills, sprite, voice and face picture. ✨ New character / class… makes a new unit from any template.

👗 Outfits

All outfits of all mods. ✨ New outfit… makes one from a sprite sheet (or from a copy of the character's sprite). The buttons under the list set face pictures and cut-in portraits, rename outfits and edit their colour parts.

📊 Database Editor

All 90 game tables as spreadsheets: items, skills, evilities, classes, stages, quests, shops, Dark Assembly… Column headers explain each field when you hover them. You can export to CSV and import back.

✨ Skills & Animations

What a skill looks like in battle. The 🎬 Timeline editor plays the whole skill inside the kit, the way the game shows it (its camera, effects, cut-in and the battle map; no game needed), and lets you move, retime and add effects, camera moves, poses and sounds. 🧩 Presets add ready-made dashes, jumps, close-ups, shakes, fades and hits; 🟥 Area shows and changes the panels the skill hits (and puts enemies on them to try it); 👥 Who learns it lists the characters and classes that learn it, at which level (the same list as on the Characters & Classes page). Give a skill another skill's animation, or put your own pictures into its effects. Preview in game sends your edit to the running game without a reinstall. Overloads are here too (the Overloads category, ⚡ New Overload…): see below.

💬 Dialogue & Text

Search all 7,000 conversations, edit lines in every language, change speakers, add or remove message boxes, and find & replace across the whole game.

🗺 Stages & Maps

Battle maps: move, add or delete enemies and change their class, level, equipment and skills. Paint Geo Panels, place Geo Symbols, move the base panel, clone a stage.

🎨 Sprites & Colors

Every character and monster sprite with a live animated preview. Click the character to select a part, then drag hue, saturation and brightness. Export sprite sheets, repaint them, import them again.

🗡 Weapon Grips

Where each character holds its weapon, per animation and frame: drag the weapon onto the hand.

🖼 Textures & UI · 🎵 Music & Sound

Menus, windows, icons and logos as PNG pictures; all background music and sound effects. Replace them with your own.

🧩 Event Scripts · 📦 Archive Explorer advanced

All 19,000 event scripts as editable text, and every file inside every game archive (preview, export, replace).

Turning mods on and off

  1. On the Home page the Mods list is grouped by category: Systems, Outfits (each with its character), New characters, Classes & monsters, Skills, Gameplay … Tick or untick a mod, or a whole group at once (a half-filled box: some of it is on).
  2. Type in the search box to find a mod by its name, a character or an outfit name.
  3. Click a mod: What it adds says it in words (its outfits by name, new characters, classes, skills, quests, database changes, sprites) and which mods need it; its files are listed below.
  4. Load order (button above the list) shows the order mods are installed in: drag to reorder. When two mods change the same thing, the lower one wins.
  5. Press ⚡ Install & Play (or Install only). The game gets exactly the ticked mods.

Packs. Select several mods (Ctrl+click), right-click › Group into a pack…: they show and switch as one entry. A pack only groups them: the mods themselves don't change, and Ungroup undoes it.

A mod that needs another one (every outfit mod needs Outfit System) shows ⚠ when that one is off; ticking it switches on what it needs too. Right-click a mod for more: edit its details (and its category), open its folder, share it, make your own version of it, delete it.

Restoring the original game

Home › Restore original game… puts every changed game file back exactly as it was before the first install. Your mods stay in the kit; install them again whenever you like. Do this before uninstalling the kit or deleting its folder.

Tutorial 1 · Your first edit

Rename Killia and give him more HP.

  1. Home › ＋ New mod. Name it My First Mod. Your edits now go into it.
  2. Open 🧙 Characters & Classes and pick Killia — Wanderer in the list.
  3. Change Name (English), and raise the HP base value (first row of Base stats).
  4. Press 💾 Save. The status box turns orange: Changes not in the game yet.
  5. Press ⚡ Install & Play, load a save and look at Killia's status.
To undo it, untick My First Mod on the Home page and install again. Or select the change in the mod's file list (right side of Home) and press Remove selected change.

Tutorial 2 · A new recruitable character

  1. Characters & Classes: select the character to start from (for example Seraphina). The new one copies its stats, skills and evilities.
  2. Press ✨ New character / class…. Choose Unique character, give it a name, title and up to three lines of description.
  3. Look: The template's look (keep Give it its own copy of the sprite ticked to recolour or repaint it), or any outfit of your outfit mods — Killia — Formal, Etna — …. A Disgaea RPG outfit is drawn again as a complete character of its own (every animation, face, portrait, cut-in); another outfit's sprite is copied. Tick Take that outfit out of the Outfit menu if it should only exist as the new character: your mod hides it, the outfit's own mod is not changed, and units already wearing it keep it.
  4. Stats: keep the template's or start from a preset (All-rounder, Heavy hitter, Spellcaster, Defender, Speedster, Gunner, Healer, Overlord — the numbers of one of the game's playable characters).
  5. Keep Save it in a new mod of its own ticked: one character = one mod, easy to share, update or switch off.
  6. Keep Make it recruitable with a new quest ticked and write the quest title, client and text. Long text is split into the quest board's lines for you.
  7. OK. Then shape it on the page and 💾 Save:
    • Quick setup: another preset, or 📋 Copy from another… — any character's or class's base stats, aptitudes, movement, mastery, resistances, evilities, Overload or skills, base stats at a power % of your choice.
    • ✨ New skill of their own…: a copy of any skill (its numbers and animation) with its own name, SP cost and learn level. Tick Then open the skill editor: the timeline editor opens on it, and ↩ Back to …'s setup brings you back.
    • ✨ New evility of their own…: your own name and description; in battle it works like an evility of the game you choose.
    • Evilities, Overload and learned skills are drop-down lists; hover an entry to read what it does.
    • For its own face, press 🙂 Face picture… (a square picture, about 200×200).
  8. Install. In game, accept the quest at the Quest Shop, complete it and report back: the character joins.

Choosing a generic class (for example Warrior) as the template makes a new class (six ranks, hired at the Recruiter) instead.

Tutorial 3 · An outfit from a sprite sheet

A sprite sheet is a picture with one row of frames per animation (stand, walk, attack…), front and back views, like the Disgaea RPG frame dumps. D5ModKit\SpriteSheet contains examples.

  1. 👗 Outfits › ✨ New outfit….
  2. Choose the Character, type the Outfit name shown in game, keep Convert a sprite sheet and pick the PNG.
  3. Optional: a Face picture (square; tick Mirror if it looks to the right) and a Cut-in portrait (tall; white backgrounds are removed).
  4. OK. The kit matches every frame to the game's own poses: the outfit animates exactly like the character, with colour variants made automatically. Check it in the preview.
  5. Install. In game: Characters › the character › Outfit.
Colours look off in some poses? 🖌 Parts opens the part painter: paint a few poses and the kit fixes the rest. The in-game colour editor then works per part (hair, clothes, skin…).

Tutorial 4 · Recolouring a sprite

  1. 🎨 Sprites & Colors: search the character and select it. Pick the colour variant (Normal Color, Extra Color 1–4) at the top.
  2. Click the hair (or any part) in the live preview: its shades are selected.
  3. Drag Hue, Saturation and Brightness. The animation updates as you drag.
  4. 💾 Save, then install.

For a full repaint use the 🖼 Sprite sheets tab: Export all sheets…, paint them in any image editor (keep the size and layout), then Import all sheets….

Tutorial 5 · Disgaea RPG outfits command line

The kit builds Disgaea RPG looks for the game's characters by itself. It uses the DRPG sprites in D5ModKit\DRPG Assets (Updated) and the list in d5lib\data\drpg_outfit_catalog.json.

  1. Find the DRPG unit numbers in DRPG Assets (Updated)\Units IDs.txt.
  2. Open d5lib\data\drpg_outfit_catalog.json in Notepad. Find the character (for example "name": "Etna", "class": 520) and add [unit number, "Outfit name"] to its "outfits" list.
  3. Double-click D5 Mod Kit Console.bat and type 
    python tools\drpg_outfits.py check
python tools\drpg_outfits.py build 520
    (520 is Etna's "class" number in the catalog). Each outfit takes a few seconds.
  4. Back in the kit, the outfits are in 👗 Outfits. Install and play.

A character that's new to the catalog needs its twin: the DRPG unit drawn exactly like the game's own sprite. Then run python tools\drpg_outfits.py learn CLASS once. See docs\OUTFITS.md for details, including new playable characters ("kind": "new_character").

Tutorial 6 · Weapon grips

  1. 🗡 Weapon Grips: choose the character, weapon type and animation.
  2. Drag the weapon onto the hand. Right-drag rotates it, the arrow keys nudge it, Q/E turn it and F mirrors it.
  3. Choose whether the change applies to this frame or the whole animation, play it back, then 💾 Save and install.

Tutorial 7 · A skill's animation

  1. ✨ Skills & Animations: search a skill (for example Mega Fire).
  2. Quick change: 🎬 Use animation of… plays another skill's animation instead.
  3. Your own version: open the 🎬 Timeline editor tab and press ▶ — the skill plays right there, with its camera, on a battle map. The first edit makes an editable copy in your mod. Drag effects in the preview or on the timeline. Right-click the timeline to add effects, poses, sounds and presets.
  4. Click anything to see it in ✏ Properties: folding panels (Transform, Timing, Drawing, Motion …) with a line of help under each setting. An effect drawn over a character when it should be under it (or the other way round): Drawing → Draw order and Nearer camera — they write the game's own commands, so the game draws it the same way.
  5. Poses and sounds are chosen by sight and by ear: 🏃 Change pose… shows every pose playing its animation, 🔊 Choose by ear… lists the sounds with their waveform and the skills that use them (click to hear).
  6. The badge at the top right of the preview says which camera you see: 🎥 Game camera (the skill's own, moving as in the game) or the free camera you get by looking around with the middle / right mouse button — click the badge, press C or play the skill to go back.
  7. Building blocks: the 🧩 Presets tab — for example Dash to the target and back, Close-up, Quake, Hit. Set the values, ➕ Add at frame…, then move it on the timeline.
  8. Where it hits: the 🟥 Area tab. Click panels to change the area, set how far the cursor reaches, and use Place enemies to see the skill hit several enemies. 💾 Save area writes it into your mod.
  9. Optional: Preview in game sends your version to the running game (edits show up without reinstalling).
  10. 💾 Save, then install to keep it. New pictures (Effects & pictures tab) need an install and a game restart.

Give a skill to a character with ➕ Give to character… or on the 👥 Who learns it tab (change the level there, or remove it). More in docs\SKILL_EDITOR.md.

Overloads. Press ⚡ New Overload… (or pick one of the game's in the Overloads category): give it a name and description, and choose what it does on the ⚡ Overload tab — the code of a game Overload (giant, extra actions, revive…) or numbers of its own (power, element, area, effects). Its name gets a title banner of its own (pick the style and colours, or use your own picture). Its animation is edited on the Timeline editor like any skill's. ➕ Give to character / class… hands it to anyone, new characters included. In battle it needs Revenge Mode, as always. More in docs\OVERLOADS.md.

Tutorial 8 · Dialogue and text

  1. 💬 Dialogue & Text: search for a word from the line you want to change.
  2. Select the message, edit it in Edit selected message, and change the speaker if needed.
  3. 💾 Save and install. For mass edits use Find & Replace….

Tutorial 9 · A stage's enemies

  1. 🗺 Stages & Maps: pick a stage. The map shows enemies, Geo Panels and the base panel.
  2. Add enemy, click a panel, then set its class, level, equipment and skills on the right.
  3. 💾 Save, install, and play the stage. Clone as new stage… copies a stage for your own level.

Tutorial 10 · Music and sounds

  1. 🎵 Music & Sound: pick a track. Play it, or Replace with my song….
  2. WAV files work as they are. For MP3, OGG or FLAC, install ffmpeg and make sure ffmpeg.exe is on your PATH.
  3. Install, then listen in game.

Tutorial 11 · Database (items, skills…)

  1. 📊 Database Editor: choose a table (for example item), search for the row and change the value. Hover a column header to see what it means.
  2. 💾 Save, then install. Changed rows only shows what your mods change. CSV export and import let you work in Excel.
Don't delete the game's own rows: saves refer to them. Add new ones instead. The kit always gives new things ids above the existing ones.

Tutorial 13 · New classes and monsters command line

Make a generic class or monster from a Disgaea RPG unit, animated like a vanilla class or monster:

python tools\new_drpg_class.py UNIT TEMPLATE "Name" --titles "T1,T2,T3,T4,T5,T6" --desc "one line for Hire Character"
python tools\new_drpg_monster.py --help

Run them in D5 Mod Kit Console.bat. docs\CLASSES.md and docs\MONSTERS.md explain every step.

Tutorial 14 · Sharing your mods

With other kit users
Home › right-click a mod › Share (export as .zip)… (or 📤 Share this character… on the Characters page). Give it a version. They use Home › More ▾ › Import / update from .zip… and install.
With players (no kit)
One installer .exe with your mods: they run it, press Install, done. Uninstall restores their game exactly. 
python tools\export_pack.py "My Mods.exe" --title "My Disgaea 5 mods"
Details: docs\SHARING.md.

Updates never break saves. A shared mod carries an identity: importing a later version of a mod you already have updates it (the old version is kept in D5ModKit\state\mod_backups). When a mod you import uses an id one of your other mods already uses (two people both made a character in the same free slot), the kit moves it to a free one and remembers that, so every update lands on the same ids and recruited units stay what they are. Your other mods are never changed.

Building on someone's work. Right-click their mod › Make my own version…: a copy with its own identity that remembers where it came from (shown under the mod's description). It takes the original's place in the game; the original stays as it was, switched off, and can still be updated.

To share the whole kit like this package, run python tools\make_release.py OUTPUT_FOLDER --zip.

Command-line tools

Double-click D5 Mod Kit Console.bat: a command prompt where python is the kit's own Python. The tools work on the game folder the kit uses.

CommandWhat it does
python tools\install_mods.pyInstall the enabled mods (the same as the Install button).
python tools\drpg_outfits.py check | learn | buildDisgaea RPG outfits (Tutorial 5).
python tools\new_drpg_class.py · new_drpg_monster.pyNew class / monster from a DRPG unit.
python tools\export_pack.pyMake a player installer .exe.
python tools\make_release.pyMake a shareable copy of the whole kit (like this one).
python tools\skilledit.pySkill animations from the command line.
python tools\grips.py · partcli.pyWeapon grips · outfit colour parts.
python tools\qa_sprite.py · render_skill.pyCheck a built sprite · render a skill's frames.

Run any of them with --help for its options. The other files in tools (d5ctl, battle_nav, walk…) drive the game for automated tests. They need remote=1 under [debug] in d5auto.ini and are for developers.

Changing the C source of the game runtime (d5lib\native) needs the Zig compiler: runtime\python.exe -m pip install ziglang. Everything else works without it.

Troubleshooting & FAQ

"Disgaea 5 Complete was not found"

Choose the folder that contains disgaea5.exe and Data (Home › Change game folder…). Steam shows it under Manage › Browse local files.

⚠ "This disgaea5.exe is not the version the kit was made for"

The kit was made for the PC release's program file (its last update was in October 2018). If another tool changed your exe, verify the game files in Steam and start the kit again. With a really different version, the mods that change the game program (outfits, new characters and classes, colour slots, skills) refuse to install safely, with a message. Data-only mods still work.

⛔ "The game already has mods from another copy of the D5 Mod Kit"

Another kit folder (or an older copy of this one) installed mods into this game. Press Restore original game… in that copy first, or copy its state folder into this kit (it holds the backups), or verify the game files in Steam.

⛔ "A mods package is installed in this game"

A player installer .exe made with the kit is installed. Run it again and press Uninstall first.

The install failed

Close the game, then try again. The message (and the Log) says which file or mod caused it. If the game is under C:\Program Files, start the kit as administrator.

Steam updated or verified the game, and the mods are gone

Press Install & Play again; the kit keeps its backups.

The game crashes

Note what you were doing. Then restore the original game and install again with fewer mods ticked to find the cause. Check d5auto.log in the game folder: it records what the runtime did. Keep a backup of your saves.

Uninstalling the kit

Home › Restore original game…, then delete the D5ModKit folder. The game folder may still hold files the mods' runtime made while you played: d5auto.log, d5looks.bin, d5core_live*.dll and d5live_script.dat. Delete them too if you like.

Updating the kit

To move to a newer copy of the kit without losing anything:

  1. In the old kit, press Restore original game….
  2. Copy your own mods (any folder in old\mods you made) into the new kit's mods folder.
  3. Start the new kit and install.

Or copy the old kit's state folder into the new one instead of restoring. It holds the backups of the original game files, so the new kit takes over where the old one left off.
